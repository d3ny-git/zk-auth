# Test vectors

* `metamask_personal_sign.json`: `personal_sign` signatures made by
  `@metamask/eth-sig-util`'s `personalSign`, the function MetaMask's keyring
  runs for that RPC. Generated by `tests/e2e/gen-metamask-vectors.mjs` with
  public test keys. The "Hello, world!" entry reproduces the signature
  published in eth-sig-util's documentation.
  These were **not** captured by clicking "Sign" in the MetaMask extension
  (that needs a person at a browser). To add such a vector, open the client
  with `?debug=1`, sign in, and paste the JSON printed under step 5 into this
  file. `tests/test_eth_sig.cpp` checks every entry.
